# Commits d'amorçage exemptés du verrou de revue de la PR de publication (AD-24, D-13 ; arbitrage
# d'Arnaud du 25/09/2026, story 11.7).
#
# Le verrou exige que chaque commit de « main..dev » soit le squash d'une PR fusionnée par
# verify-and-merge-pr. Le marqueur « (#N) » ne le prouve pas : Gitea l'ajoute à **tout** squash. Ce
# fichier nomme donc les seuls squashs qui n'ont pas pu passer par ce script — ils ont été fusionnés
# à la main sous la règle d'amorçage, avant que le script existe (livré par la story 0.7, PR n° 11).
# Pour tout autre commit, la règle reste stricte.
#
# Trois options ont été écartées : interroger la forge PR par PR (preuve réelle, mais 113 appels et
# une dépendance réseau dans un verrou de fusion, alors qu'AD-14 prévoit que le homelab tombe), une
# borne d'amorçage assumée (« tout ce qui est avant X passe » ne dit ni combien ni lesquels), et une
# revue rétroactive de la plage (le verrou vérifie la provenance, pas seulement l'existence d'une revue).
#
# Format : un SHA complet (40 hexadécimaux) par ligne, suivi de la raison. Un SHA mal formé est une
# anomalie, jamais une ligne ignorée. Les deux premiers sont déjà sur main : ils n'apparaissent donc
# plus dans « main..dev », et restent listés parce que la liste dit quels commits ont échappé au
# script, non lesquels restent à publier.
