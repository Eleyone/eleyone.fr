This site is a set of static pages. It has no database, no form, no account and no analytics.

## What this site does not do

- **No cookie, no tracker.** Not for analytics, not for advertising, not for consent — there is nothing to consent to.
- **No JavaScript.** The pages are HTML and a stylesheet.
- **No resource loaded from a third party.** No font, no script, no image, no icon set. Your browser contacts nothing but this site's server.
- **No personal data collected.** Nothing is asked, nothing is recorded, nothing is passed on.

## Server logs

The server that delivers these pages writes one line per request: the date, the method, the path requested, the response code and the number of bytes sent. **No IP address, no user agent, no referrer.** Those lines cannot reconstruct a visit or identify anyone.

## Links to other sites

Some pages link to third-party sites: the site's own source repository, legal texts, and — where a case has any — **videos hosted by YouTube**. These are links, never embedded players: nothing is loaded from those sites until you click.

Following such a link takes you to a third party, which applies its own rules. For YouTube, those are Google's.
