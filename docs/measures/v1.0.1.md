## Écarts relevés

- **404** : « Bonnes pratiques » perd l'audit « erreurs dans la console » et « SEO » l'audit « code
  HTTP en échec », tous deux causés par le statut 404 lui-même, attendu sur cette page.
- Audits informatifs, sans effet sur les scores : « requêtes bloquant le rendu » et « arbre de
  dépendances réseau » (la feuille de style unique, chargée en `<link>`, AD-3) ; « améliorer la
  livraison des images » sur l'accueil et « À propos » (le portrait, déjà servi en WebP 1x/2x, AD-19) ;
  « reflow forcé » sur la page de cas (le site n'a aucun JavaScript : mesure du navigateur de l'outil).
